# Sales Automation & Dashboard

An automated Excel Sales Dashboard built using Power Query, PivotTables, Slicers, and VBA.

## 📌 Project Overview

This project automates the process of transforming raw sales data into an interactive business dashboard.

The workflow is:

**Raw Sales Data → Power Query Cleaning → Calculations → PivotTables → Dashboard**

A VBA button allows the user to refresh the complete dashboard with one click.

## 🚀 Key Features

- Automated sales data cleaning using Power Query
- KPI calculations
- Total Sales
- Total Profit
- Total Orders
- Quantity Sold
- Average Order Value
- Sales analysis by Region
- Profit analysis by Region
- Sales analysis by Category
- Profit analysis by Category
- Sales analysis by Product
- Quantity analysis by Product
- Monthly Sales Trend
- Monthly Profit Trend
- Interactive Region, Category and YearMonth slicers
- One-click dashboard refresh using VBA

## 🛠️ Tools & Technologies

- Microsoft Excel 2019
- Power Query
- PivotTables
- PivotCharts
- Slicers
- VBA

## 🔄 Automation Workflow

1. Paste new sales data into the `tblSales` table.
2. Click the **REFRESH DASHBOARD** button.
3. Power Query processes the data.
4. Calculations update automatically.
5. PivotTables refresh.
6. Charts and slicers update.
7. Dashboard displays the latest results.

## 📂 File

`Sales_Automation_Dashboard.xlsm`

> The workbook is macro-enabled, so it must be opened in Microsoft Excel with macros enabled.
